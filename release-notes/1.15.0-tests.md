## 原因与关键改动

- 原轮询每两秒公开切换 `isChecking`，助手据此更换“重新检测”的图标和标题，产生闪烁。现在只有主动重检测使用忙状态；后台访问移出主线程，并合并并发刷新、去重候选进程。
- 原 `testSelf` 不接受选中的草稿模式，始终强制 `.send`。同一固定示例又被发送账本拦截，用户选择填写仍收到发送/重复发送反馈。现在测试方式显式传入，生产配置不会被测试覆盖，示例携带本次时间；原有正式发送账本、草稿保护和本人识别保留。
- 原助手在下方空间不足时直接覆盖设置窗口内部。现在只选择外部位置，实在无空间就隐藏，主卡片仍保留按需恢复说明。
- macOS 的 AX 访问拒绝和进程通信失败分别处理，不把通信异常直接当成用户已授权。判定参考 [Apple AXUIElement 文档](https://developer.apple.com/documentation/applicationservices/axuielement_h) 和 [AXIsProcessTrustedWithOptions 文档](https://developer.apple.com/documentation/applicationservices/1459186-axisprocesstrustedwithoptions)。产品不读写 TCC，不自动重置系统权限，也不改变签名要求来绕过授权。

## 安装、清理与未实测边界

通过 GitHub v1.15.0 Release 获取通用 DMG / ZIP，或在原 App 的“检查更新…”查看简介后安装；完整源码和报告一并提供。关闭转发可在设置页右键“一键转发 Todo”入口操作，不需要在方式卡片中增加重复开关。

正式正文、历史备份、发送账本与提醒状态哈希未变；提醒运行日志正常追加，不回滚用户数据。临时测试授权已撤销，测试通知与 LaunchAgent 已清空。已归档验证后移除 9 份构建、测试和本地验收 App，备份清理 6 个测试配置域及附属测试缓存，系统搜索只剩正式安装。GitHub 下载验收后的最终核验另附。

未完整实测：系统设置实际接受从图形助手直接拖入、浮动助手长时间逐帧闪烁对比、外部应用完全卡死时的交互、Intel 硬件/macOS 13 实机、飞书未运行时冷启动、真实中文组合输入的重启瞬间。不能将代码检查或旧版验收写成这些场景已通过。客户端发送操作也不等于服务器送达回执。

当前仍为临时签名发行，更新后可能需要移除旧辅助功能条目并添加当前版本；不能承诺旧的绿色开关代表新版本实际获准。保留原生授权流程，不伪造权限。
