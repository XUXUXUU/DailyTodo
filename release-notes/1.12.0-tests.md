# Daily Todo 1.12.0 测试报告

日期：2026-11-06。版本：1.12.0，构建 23。真机：Apple Silicon / macOS 26.4.1。

## 修改

- 新增飞书自动化配置、桌面操作控制器与二级设置卡片。
- 设置可选择收件人、本人聊天、填入草稿或直接发送；新功能默认关闭、默认草稿，旧的唤起开关不会自动升级成发送权限。
- 新手引导扩展为四步，加入自动化入口；启用后按钮为“发给瑶总”，自定义收件人时跟随姓名。⌘⇧C 保持纯复制。
- 使用真实 macOS 辅助功能授权；等待飞书启动与前台稳定，精确筛选联系人，并核对聊天标题、唯一输入区、焦点、正文和附件区域。
- 对真实草稿、读取失败、遮挡、焦点变化、发送键未知和重名联系人停止操作；通过持久文件锁记录避免重复发送。
- 发送前重新将本次不可变 Todo 快照写入剪贴板，粘贴后核对完整正文。执行发送后只说明已执行客户端操作，最终状态以飞书为准。

主要文件：`FeishuAutomation.swift`、`FeishuAutomationPolicy.swift`、`AutomationSettings.swift`、`Views.swift`、`StableEditor.swift`、`OnboardingView.swift`、`App.swift`、`Info.plist`、Xcode 工程及测试/发布工作流。

## 限制与未实测项

- 正式收件人为用户配置，默认何雪瑶；正式版首次授权和配置按用户要求由用户自行体验。
- 没有飞书服务器送达回执。网络断开或客户端后续发送失败，以飞书显示为准；系统不会自行重发。
- 未退出用户飞书账号验证未登录场景，未卸载飞书验证缺失应用场景。
- 未实际上传各类附件、制造同名联系人或高频并发手动干扰；这些路径有停止保护，不能据此声称全部实机验证。
- 当前采用 ad-hoc 签名，尚无 Apple Developer ID 公证。更新构建后，macOS 可能需要移除旧授权条目、添加当前应用并重启。应用会读取真实状态并提供指引。
- 未在 Intel 真机或 macOS 13 实机测试。本轮未重测所有实际中文输入法、真实跨日或睡眠唤醒。
