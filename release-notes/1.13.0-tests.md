# Daily Todo 1.13.0 验收报告

日期：2026-11-07。版本 1.13.0 / 构建 24。Apple Silicon，macOS 26.4.1，中文飞书客户端。

## 主要修改

- 入口统一为“一键转发 Todo”，主按钮只按开关显示“一键转发”或“复制全部”。正式收件人固定为何雪瑶，移除姓名编辑和本人收件人开关。
- 保留旧配置格式；旧自定义目标迁移为关闭，避免升级后未经确认改发正式目标。旧 draft 值改为“确认后发送”，在应用内确认正文后真正发送；另保留“直接发送”。
- 新增“发给自己测试”：从当前飞书账号卡片读取姓名，等待完整内容稳定，再核对本人聊天专用输入标记；发送固定测试文案，不使用工作正文，也不更新当天完成状态。
- 重做蓝色玻璃卡片、大纸飞机和悬停光效，删除重复二级说明。保存后停留在成功页；引导完成页显示真实提醒时间及开关状态。
- 新增固定尺寸的辅助功能跟随小窗、定位当前应用和真实授权反馈；不自动开启系统权限，不修改 TCC 数据库。
- 收敛发送授权策略，保留草稿、正文、焦点、附件和持久去重检查；移除不再使用的 FeishuLauncher 旧唤起路径。

修改文件：Sources 中的 AccessibilityGuide、AutomationSettings、FeishuAutomation、FeishuAutomationPolicy、OnboardingView、Views、StableEditor、App；删除 FeishuLauncher；更新工程、版本、README、测试和 CI/发布流程。

## 异常原因与修正

1. 本机正式安装仍为 v1.11，只能打开飞书；v1.12 的默认 draft 分支在填写后就返回，并不执行发送。新版把默认行为明确改为应用内确认后发送，纯复制保持只复制。
2. 飞书账号卡片是异步分批呈现的：最初只有空 WebArea，也可能先出现组织名。真机首轮均安全停止，没有误发。现在等待经验证的账号内容和结构连续稳定，排除组织名先加载的状态，并在最终粘贴前再次要求本人专用标记。
3. 审查发现权限失效后无法关闭转发的死结，已修复：开启需要权限，关闭和保存关闭状态不要求权限。

## 限制和未实测

- 辅助功能小窗的逐屏实际跟随、定位按钮与所有显示器组合未逐项实机观察；已通过几何验证及静态检查，不将它们列为全部视觉验收通过。
- 仅在当前中文飞书客户端实测本人识别，其他语言/版本和账号布局可能无法识别，将安全停止。未测试其他人的真实账号。
- 飞书不提供独立服务器送达回执，应用只确认客户端执行与输入区清空，最终结果以飞书为准；不确定结果不会自动重发。
- macOS 撤销权限后，已运行进程的系统授权缓存可能要重启后更新。当前仍为 ad-hoc 应用签名，未进行 Apple Developer ID 公证，更新后可能需要重新添加辅助功能权限。
- Intel / macOS 13 未在真机测试。本轮没有重新实测全部中文输入法、真实跨日及睡眠唤醒，也没有制造全部附件/同名联系人场景。
