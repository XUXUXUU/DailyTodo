# Daily Todo 1.11.0 测试与交付报告

验收日期：2026-11-06。版本：1.11.0（构建 22）。真机：Apple Silicon、macOS 26.4.1。GitHub 构建环境：macOS 15。

## 修改文件

- `Sources/AppUpdater.swift`、`App.swift`、`Views.swift`：菜单与设置内检查更新、中文更新说明、下载校验、安装与重启。
- `Sources/MenuLocalization.swift`、中文资源、`Info.plist`：菜单汉化，保留原生菜单动作与快捷键。
- `Sources/FeishuLauncher.swift`、`Views.swift`：复制成功后唤起飞书，默认开启且可持久关闭，统一蓝色图标。仅打开，不粘贴或发送。
- 构建、打包脚本及 GitHub Actions：固定并校验 Sparkle 2.10.1；通用应用、DMG、签名 ZIP、签名 appcast、校验和及版本发布。私钥不进入源码和安装包。
- 原有数据格式、提醒、编辑器与快捷键实现沿用。
